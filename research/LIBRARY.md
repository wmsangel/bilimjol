# Виртуальная библиотека — scoping

Задача из очереди ROADMAP. Здесь — замысел и проработка до старта. **Это ещё не
сделано**, статусы — в `research/ROADMAP.md`.

## Замысел

Раздел `/library` на сайте — каталог **бесплатных учебников и учебных материалов**,
собранных в одном месте: по **странам**, **классам** и **предметам**. Плюс отдельная
рубрика **«книги на лето»** (списки художественной литературы по возрастам).

Гипотеза ценности: огромный органический спрос («учебник N класс скачать бесплатно»,
«окуу китеби N класс») + новые индексируемые страницы → сильный трафик-магнит под нашу
органику-стратегию. Удерживает родителей/учеников на сайте рядом с заданиями.

## ⚠️ Критично: только легально открытый доступ

Ссылаемся/встраиваем **только официальные и авторизованно-бесплатные** источники:
госпорталы образования, электронные учебники от министерств/издательств, Creative
Commons, общественное достояние. **НЕ** агрегируем пиратские PDF — для детского сайта
это юридический и репутационный риск, и против чистого подхода владельца. Для каждой
книги храним источник и статус прав (`source`, `license`).

## Источники по странам — ПРОВЕРЕНО (ресёрч 2026-10-16)

Главный вывод: предпосылка «во всех СНГ учебники бесплатны» верна **не везде**.
Реально сильный бесплатный источник — Кыргызстан; Казахстан и Россия в основном платные.

- **Кыргызстан — ✅ kitep.edu.kg** (официальная платформа Минпросвещения КР, ссылка на
  edu.gov.kg). **Бесплатно** («Бардык материалдар акысыз»). Каталог: класс 1–11
  (`/grade/N`) → предмет → книга. **471 книга, 3 языка** (кыргызский 245, русский 207,
  узбекский 19), 32M просмотров. Deep-ссылки: `https://kitep.edu.kg/grade/<класс>`.
  ⚠️ SSL: strict-клиенты (WebFetch) не верят сертификату; в браузере открывается — перед
  запуском перепроверить, что у пользователей нет предупреждения.
- **Беларусь — ✅ e-padruchnik.adu.by** (Академия национального образования РБ, раздел
  «Электронная библиотека» на adu.by). **Бесплатно скачать** электронные версии учебников,
  фильтр по ступени/классу/году/языку обучения (белорусский, **русский**). Ссылаемся на
  каталог целиком (чистых per-class URL нет — там фильтры). Добавлено в /library.
- **Казахстан — ❌ платно.** `opiq.kz` с 1 сентября стал платным (подписка); официальные
  ссылки ведут на платные ресурсы. Чистого бесплатного официального источника не нашёл.
- **Россия — ❌ в основном платно.** Учебники ФГОС платные; РЭШ (`resh.edu.ru`) и «Моя
  школа» — уроки/материалы, не сами учебники.
- **Узбекистан / Таджикистан / др.** — не проверял; добавлять только при наличии реально
  бесплатного официального источника.
- **«На лето» (худлит)** — классика в общественном достоянии: Викитека, Project Gutenberg;
  списки внеклассного чтения по возрастам. Это безопасный универсальный раздел.

**Вывод для дизайна:** строим вокруг **Кыргызстана** (kitep.edu.kg) — реальный бесплатный
официальный источник; **ссылаемся наружу (deep-link), не зеркалим**. Другие страны — только
если найдётся бесплатный официальный источник; платные отмечать явно или не включать.

## Предполагаемая структура (черновик)

- Данные: `book = { country, grade, subject?, title, lang, url, source, license, year }`.
  Отдельный тип/набор для «на лето»: `{ ageFrom, ageTo, author, title, url?, note }`.
- Страница `/library` с фильтрами: **страна → класс → предмет**; поиск по названию.
- Под-страницы (SEO): `/library/<страна>/<класс>` — индексируемые («учебники 5 класс …»).
- Рубрика «на лето» — отдельная курируемая секция, списки по возрастам, ссылки на
  легальные тексты классики.
- Двуязычно (RU/KY), как весь сайт.

## Монетизация / партнёрки (опция)

Вопрос владельца: есть ли партнёрки у ЛитРес и т.п.?

- **ЛитРес — ✅ прямая партнёрская программа** (litres.com/company/partners/): до **25%** с
  покупки приведённого читателя, cookie 30 дней. Регистрация + заявка (~2 раб. дня, могут
  отказать). Для ИП/компании — агентский договор.
- ⚠️ **Выплаты в КГ под вопросом:** ЛитРес — российский, выплаты, вероятно, на российские
  реквизиты/карту. У владельца — ИП КГ. Перед подключением проверить, можно ли реально
  получить деньги в Кыргызстане (иначе смысла нет). Аналогично Ozon/Wildberries/Book24
  (RU, часто через Admitad) — та же проблема вывода.
- **Как встроить, не ломая «бесплатно-первый»:** партнёрские ссылки уместны только в
  разделе «на лето» как ВТОРАЯ опция рядом с бесплатной («читать бесплатно на Викитеке» +
  «купить/слушать аудио на ЛитРес»). Учебники оставляем чисто бесплатными (гос-источники).
- erid/маркировка: партнёрские ссылки — это реклама, нужна маркировка (erid) по закону РФ,
  если льём на РФ. Для органики без РФ-таргетинга — проверить применимость.
- **Вывод:** интересно как вторичный доход, но упирается в вывод денег в КГ. Сначала решить
  payout, потом внедрять — не раньше.
