# Раздел «Для самых маленьких» (садик · нулевой · начальные классы)

Источник: #идеи владельца 16.11.2026. Аудитория — дошкольники и 1–2 класс
(родители выбирают, дети играют). Канал — органика (печать + игра).

## Структура

Хаб `/ru/kids` (+ `/ky/kids`), под ним:
- `/ru/kids/raskraski` — печатные раскраски (PDF).
- `/ru/kids/igry-pechat` — печатные игры (лабиринты, найди-пару, соедини точки).
- `/ru/kids/origami` — оригами/самолётики с инструкциями (PDF).
- `/ru/kids/igra` — большая полноэкранная игра (отдельный трек, позже).

## Два трека, разная вместимость

### A. Печать (PDF через страницу) — дёшево, раньше, партиями
Каждая печатная единица = страница + кнопка «Скачать PDF для печати». Это файл
через страницу — ложится на ИИ-устойчивую границу сети (как печатный лист
математики, фича Ф1 из плана). Генерация PDF на сервере/воркере; превью на
странице (SEO-контент: что внутри, для какого возраста, как использовать).
- Раскраски: тематические наборы (животные, цифры, буквы, транспорт).
- Печатные игры: лабиринты, «найди пару», соедини по точкам, «что лишнее».
- Оригами/самолётики: пошаговые схемы (PDF) + короткий текст.
**Перед масс-производством раскрасок/оригами — проверить спрос** (GSC/Яндекс по
RU/KY: «раскраски распечатать», «оригами схемы», «лабиринты для детей»); рынок
раскрасок перенасыщен — брать нишу (кыргызские мотивы, двуязычные подписи,
школьная подготовка), не «ещё один сайт раскрасок».

### B. Большая игра — крупное, по фазам
Полноэкранная игра: персонаж проходит уровни, решая задачи для малышей (ответ
на вопрос, логика, выбрать правильный цвет, «победить» препятствие). Цель —
«увлекательно, красиво, играешь и немного обучаешься».
- **Ф1 (MVP):** движок уровней + 1 мир (10–15 уровней) + ~20 заданий (счёт до 10,
  цвета, формы, простая логика). Карта мира, прогресс, звёзды (уже есть в кабинете).
- **Ф2:** ещё миры/задания, озвучка, награды в гардероб.
- **Движок общий:** персонажи и их характеры (идея №8) и новогодняя одежда
  (сезонная задача) — НА ТОМ ЖЕ движке/маскотах, не плодить отдельных героев.
- Оценка Ф1: крупно, многонедельно (движок + контент 20 заданий + арт).

## Связка с премиумом (РЕШЕНИЕ владельца 16.11.2026)
**База — бесплатно, расширенное — в премиум:** базовые PDF (раскраски/игры/
оригами) и 1-й мир игры БЕСПЛАТНЫ (под охват и рекламу AdSense); расширенные
наборы печати и дальние миры/уровни — в ПРЕМИУМ.
**Premium-gate закладывать в архитектуру раздела СРАЗУ** — в задаче «каркас
/ru/kids» (срок 12.12), не прикручивать потом. Единый механизм гейта с задачами
«меньше бесплатных уроков» и «премиум за репост» (пакет #идеи 14.11) — одна
платная воронка на весь сайт, не отдельная для kids.
