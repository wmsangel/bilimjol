# План работ — bilimjol.com

Очередь задач для дневного авто-аналитика и для ручной работы. Составлен
2026-09-23 на основе фактического аудита репозитория, прода и среза Search
Console — не на общих соображениях. Цифры в разделе «Почему» взяты из замера,
а не придуманы.

## Как этим пользоваться

- **Одна задача за прогон.** Аналитик берёт ПЕРВУЮ невыполненную задачу сверху,
  если в тот день нет проблем поважнее (битые ссылки, 5xx, просадка трафика,
  новые «быстрые победы» в GSC — они всегда вперёд плана).
- **Сделал → билд зелёный → коммит+пуш → сразу отметил `[x]` здесь → коммит
  отметки.** Не копить отметки на конец.
- **Один пуш за прогон** (см. память `deploy-discipline`).
- **Крупное помечено `⚠️ КРУПНОЕ`** — такие задачи аналитик НЕ делает молча:
  сначала описывает владельцу план и ждёт решения.
- Сайт детский: никакой рекламы, аналитики-трекеров сверх текущей, тёмных
  паттернов. Обе локали (ru/ky) заполняются всегда.
- Промпт у каждой задачи — самодостаточный, можно скопировать в чистую сессию.

## [x] В1. Шапка: кнопка темы налезает на логотип на мобильном

**Почему.** Замерено на проде при ширине 375px: ссылка-логотип занимает
x=16–126, кнопка переключения темы ☀️ — x=96–132. Перекрытие 30px. Слово «jol»
физически лежит под кнопкой, логотип читается как «Bilimj☀️l», а тап по концу
логотипа попадает в смену темы. Видит каждый мобильный посетитель, а мобильных
у нас будет большинство.

**Что сделать.** `apps/web/src/components/SiteHeader.tsx`, `BrandMark.tsx`,
`ThemeToggle.tsx`, `LanguageSwitcher.tsx`. Пересобрать раскладку шапки на узких
экранах: логотипу дать `shrink`/обрезку или спрятать текстовую часть ниже

**Гейт.** Ни одна пара интерактивных элементов шапки не пересекается
bounding-box'ами на всех четырёх ширинах; горизонтального скролла нет
(`scrollWidth === clientWidth`); тач-таргеты ≥ 44px.

