# План сторис Bilimjol — ежедневно

Цель: каждый день — одна сторис, которая рассказывает о возможности сайта
(органика, без закупки). Канал: @bilimjol_storis_bot → аккаунт жены (она постит).

## Как это работает (механика)

- Контент — в `posts.js` (поле `week`, `format: "story"`). Один слайд-сторис =
  кикер + крупный хук + маскот.
- `telegram-daily.mjs` на автозапуске (launchd `com.bilimjol.social.telegram-daily`)
  шлёт **сторис дня** из САМОЙ ПОЗДНЕЙ недели (`storyForDay` в `plan.js`) —
  **каждый день**, независимо от публикации ленты. Присылает картинку + инструкцию
  по стикеру (какой нативный стикер добавить и куда вести ссылку).
- Лента (карусели/посты) публикуется отдельно автопостером через Chrome —
  это НЕ сторис, не мешается.
- **Ротация:** набор сторис = последняя неделя в `posts.js` (7 шт, по одной на
  день недели). Чтобы обновить — добавить новую «последнюю» неделю из 7 сторис:
  со следующего дня бот начнёт слать её. Старые недели остаются в истории.
- После правок: `node scripts/social-slides.mjs` (перерисовать PNG). Проверить
  конкретную: `node scripts/telegram-daily.mjs <id>`.

## Неделя 4 — идеи (добавить как week:4, когда неделя 3 отработает)

Углубляемся: конкретные произведения библиотеки + фичи личного кабинета.

- **Басня «Ворона и Лисица»** (/library/read/<slug>) — «читать и слушать за 2 минуты», опрос «Знаете мораль?».
- **Математика 3 класс** (/matematika/3) — задачка-квиз под крупный GSC-кластер «задачи 3 класс».
- **Помощь по алгебре 9–11** (/algebra/9) — «застрял на алгебре? разбор по темам», задачка.
- **Быстрый счёт — игра** (/games/sprint) — «сколько примеров за 60 секунд?», квиз-челлендж.
- **Отчёт для родителей** (кабинет) — «видишь, где ребёнок силён, а где нужна помощь», опрос «Знаете слабые темы ребёнка?».
- **Звёзды и гардероб** (мотивация) — «звёзды за задания → одевай героя», опрос «Что мотивирует? Звёзды · Похвала · Игра».
- **Тест «Кыргызстан»** (/tests/kyrgyzstan) — краеведческий квиз, вовлечение семьи.

## Неделя 5 — идеи

- **Логика/головоломки для дошкольников** (новый лендинг, когда будет) — задачка на логику 5–6 лет.
- **KY-фокус:** «математикалык оюндар» (/ky/matematika/igry) — топ-страница под кыргызский спрос, сторис на KY.
- **Примеры по математике** (/matematika/primery) — генератор примеров, квиз.
- **Басня №2** (другое произведение из библиотеки) — ротация литературы.
- **Мини-урок** (короткий разбор одной темы в сторис-формате).
- **Подготовка к школе — навык** (внимание/счёт) — отдельный навык как опрос.
- **Профтест для старших классов** — повтор под новый сезон.

## Правила контента

- Тон честный, без «чудо-результата». Каждая сторис = одна фишка + один призыв
  (ссылка-стикер на страницу или опрос/квиз для вовлечения).
- Темы под видимый спрос (GSC) в приоритете; квизы — реальные задачи с ответом.
- RU+KY у каждого текста; бот шлёт картинку на основном языке + подпись обе.
- Не повторять одну фишку чаще раза в ~2 недели.
