# Автопостинг постов в Instagram @bilimjol (через Chrome)

Процедура для ежедневной запланированной задачи Claude (~12:20 по Бишкеку).
**Один пост за запуск.** Молодой аккаунт — не больше 2–3 постов в день суммарно.

Контент — `social/posts.js` (несколько недель, у поста есть `week`). Картинки —
`social/out/*.png` (если нет — сгенерить `cd social && node scripts/social-slides.mjs`).
Журнал опубликованного — `social/ig-posted.json`.

## Порядок (строго)

1. **Пост дня.** В плане несколько недель, на один день недели приходится
   несколько постов — **не выбирай пост глазами по дню недели**. Решение даёт скрипт:

   ```bash
   cd social && node scripts/today.mjs
   ```

   Он печатает JSON: `action`, `id`, `files` (слайды RU по порядку), `caption`
   (готовая подпись: текст + пустая строка + хэштеги).
   - `action: "publish"` → публикуем именно этот `id`, файлы и подпись — из вывода.
     `filesReady: false` → сначала `node scripts/social-slides.mjs`, потом снова `today.mjs`.
   - `action: "story"` → **пропуск** (сторис грузит владелец, через веб нельзя).
   - `action: "skip"` → **пропуск**, причина в `reason` (уже опубликован / всё
     опубликовано / на этот день поста нет). Отчёт и выход.

   Правило (в `plan.js`): активная неделя — самая ранняя, где есть неопубликованный
   пост ленты; пост дня — пост активной недели на сегодняшний день. Пропущенный
   день не теряется: его пост выйдет в тот же день следующей недели, и только
   потом активной станет следующая неделя. Расклад на неделю: `node scripts/today.mjs --week`.

2. **Проверка аккаунта (ABORT-гейт).** Открыть `instagram.com/accounts/edit/`,
   убедиться, что активен **именно @bilimjol** (имя профиля = bilimjol). На этой
   машине в Chrome несколько IG-аккаунтов сети (ocrsnip и др.).
   - Если НЕ @bilimjol → **ABORT**: ничего не публиковать, попросить владельца
     переключить аккаунт (Switch accounts). Пароли не вводить.

3. **Публикация.** `+ New` → **Post**. Instagram раскатывает НОВЫЙ веб-композер
   частично — у части аккаунтов старый, у части новый. Смотри, что открылось, и
   умей **оба**.

   - **Загрузка файла.** `input[type=file]` НЕ виден в дереве доступности —
     проставь ему `aria-label` через JS, потом найди по нему и залей через
     `file_upload` (НЕ кликать кнопку выбора — откроет нативный диалог):
     `document.querySelector('input[type=file]').setAttribute('aria-label','igupload')`
     Одиночный пост → `out/<id>-ru-01-square.png`; карусель → все слайды
     `out/<id>-ru-NN-square.png` одним альбомом, по порядку.

   - **Старый композер:** экран **Crop** (пропорции 1:1) → `Next` (фильтры) →
     `Next` → экран подписи. Поле подписи — **contenteditable**: кликни по `ref`
     из `find` и печатай через `type`.

   - **Новый композер** (URL `/create/style/` → `/create/details/`): выбора
     пропорций **НЕТ**; редактор может показывать картинку **как будто обрезанной** —
     правду показывает **миниатюра на экране деталей** (проверь `zoom`). Поле
     подписи — обычная `textarea` с `aria-label="Write a caption…"`: заполняй
     через `form_input` (не contenteditable).

   - Подпись = поле `caption` из вывода `today.mjs` (это `caption.ru` + пустая
     строка + `hashtags.ru` из `posts.js`).
   - **FB-кросспост — OFF.** Тумблер «Share to · Facebook» проверить глазами через
     `zoom` (должен быть выключен). Кросспост в Facebook не включать.
   - **ПЕРЕД нажатием «Share»/«Поделиться» ещё раз проверь активный аккаунт**
     (имя = bilimjol в шапке композера): соседние задачи в том же Chrome могли
     переключить аккаунт. Не @bilimjol → **ABORT**, не публиковать.
   - `Share` → дождаться «Your post has been shared» → `Done`.

4. **Журнал.** Добавить `id` в `social/ig-posted.json.posted` с датой → `git add` +
   commit + push (doc-only).

5. **Отчёт.** Коротко: что опубликовал (или почему пропустил/ABORT).

## Грабли (из опыта сети: ocrsnip/pawdget, 28.10)

- **Escape в диалоге подписи → «Discard post?»** — не нажимать Escape.
- **Кликать по `ref` из `find`**, не по координатам.
- **Ждать отрисовки** между шагами (2–3 с).
- FB-тумблер проверять **зумом** (мелкий, легко ошибиться).
- Новый композер скрывает истинный кроп — сверяй по **миниатюре деталей (zoom)**.
- Активный аккаунт проверять **дважды**: в начале и прямо **перед «Share»**.
- В плане 2 недели (по 5 постов ленты + 2 сторис). Когда все посты ленты
  опубликованы, `today.mjs` отвечает `skip` — автопостер простаивает, пока в
  `posts.js` не добавят следующую неделю (`week: N+1`, те же дни, новые `id`).
