# Автопостинг постов в Instagram @bilimjol (через Chrome)

Процедура для ежедневной запланированной задачи Claude (12:20 по Бишкеку).
**Один пост за запуск.** Молодой аккаунт — не больше 2–3 постов в день суммарно.

Контент — `social/posts.js` (по дню недели). Картинки — `social/out/*.png`
(если нет — сгенерить `cd social && node scripts/social-slides.mjs`).
Журнал опубликованного — `social/ig-posted.json`.

## Порядок (строго)

1. **Пост дня.** Взять пост из `posts.js` по сегодняшнему дню недели.
   - Если `format === "story"` → **пропуск** (сторис грузит владелец, через веб нельзя).
   - Если `id` уже в `ig-posted.json.posted` → **пропуск** (уже опубликован).
   - Если публиковать нечего → отчёт «нечего публиковать», выход.

2. **Проверка аккаунта (ABORT-гейт).** Открыть `instagram.com/accounts/edit/`,
   убедиться, что активен **именно @bilimjol** (имя профиля = bilimjol).
   - Если НЕ @bilimjol → **ABORT**: ничего не публиковать, попросить владельца
     переключить аккаунт (в Chrome несколько IG-аккаунтов сети). Пароли не вводить.

3. **Публикация.** `+ New` → **Post** → загрузить картинку(и) поста:
   - одиночный пост → `out/<id>-ru-01-square.png`;
   - карусель → все слайды `out/<id>-ru-NN-square.png` одним альбомом (по порядку).
   - Файл-input скрыт: найти через `read_page`/`find` элемент `type="file"` в
     диалоге «Create new post» и залить через `file_upload` (НЕ кликать кнопку —
     откроет нативный диалог).
   - `Next` (кадрирование, 1:1) → `Next` (фильтры) → экран подписи.
   - Подпись = `caption.ru` + пустая строка + `hashtags.ru` из `posts.js`.
   - **FB-кросспост — OFF.** Проверить тумблер «Share to · Facebook» глазами
     через `zoom` (должен быть выключен). Кросспост в Facebook не включать.
   - `Share` → дождаться «Your post has been shared» → `Done`.

4. **Журнал.** Добавить `id` в `social/ig-posted.json.posted` с датой → `git add` +
   commit + push (doc-only).

5. **Отчёт.** Коротко: что опубликовал (или почему пропустил/ABORT).

## Грабли (из опыта сети)

- **Escape в диалоге подписи → «Discard post?»** — не нажимать Escape.
- **Кликать по `ref` из `find`**, не по координатам.
- **Ждать отрисовки** между шагами (2–3 с).
- FB-тумблер проверять **зумом** (мелкий, легко ошибиться).
- Текущий план — 1 неделя (5 постов ленты), все уже опубликованы: автопостер
  будет простаивать, пока в `posts.js` не добавят новые посты/недели.
