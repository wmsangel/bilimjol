# izn.study

Образовательная платформа для детей (СНГ): задания по классам от подготовки
к школе до 11 класса, геймификация, дешёвая подписка.

**Рынки:** Кыргызстан, РФ (далее — СНГ).
**Языки:** русский, кыргызский.

Полное описание решений — в [ARCHITECTURE.md](./ARCHITECTURE.md).

## Стек

Монорепо (pnpm + Turborepo): отдельный backend API + веб (Next.js) +
мобильные приложения (React Native, позже). Всё на TypeScript.

## Требования

- Node.js `>=20.18.0` (см. `.nvmrc`)
- pnpm `>=10`

## Команды

```bash
pnpm install      # установить зависимости всего монорепо
pnpm dev          # запустить приложения в dev-режиме
pnpm build        # собрать всё
pnpm lint         # линт
pnpm typecheck    # проверка типов
```

## Структура

```
apps/web      — веб (Next.js)
apps/api      — backend API (общий для веба и мобилок)
apps/mobile   — мобильные приложения (Expo) — позже
packages/shared — общие типы и логика
```
